Documentation & Guide

This tool serves two purposes: converting visual block syntax into text and vice versa. Because the text language that draws blocks is different from the text language that compiles to working Scratch code, this tool uses two different syntaxes.

1. Scratchblocks (Drawing)

This is the standard Scratchblocks syntax. It is purely visual. You upload an .sb3 file on the left side, and we extract this syntax so you can see exactly what the blocks look like and render diagrams for sharing.

when green flag clicked
move (10) steps
say [Hello, world!]

2. Fractch (Compiling)

To compile text back into a working .sb3 file, we use a tool called Fractch. Fractch uses a more standard programming language syntax that logically maps to Scratch's AST.

  • Files must start with a target declaration, e.g., sprite "Sprite1";
  • Hats use the when keyword, e.g., when flag at 0,0 { ... }
  • Arguments are placed after the keyword, e.g., move 10;
  • Strings use quotes, e.g., say "Hello, world!";
sprite "Sprite1";

when flag at 0,0 {
  say "Hello, world!";
  move 10;
}

Write your Fractch code on the right side and click "Compile" to download a working .sb3 project containing your sprite and scripts!
